# 💸 Personal Expense Tracker with Budget Alerts

A full-stack web application built with **Flask** and **PostgreSQL** to log daily expenses, track category spending visually, set monthly budget limits, and receive live budget alerts.

## 🌟 Features
- **Dashboard:** Log expenses by amount, category, and date.
- **Visual Breakdown:** Interactive donut chart powered by Chart.js.
- **Budget Alerts:** Live warning badges (`⚠️ Over Budget!`) when limits are breached.
- **Full Management:** Add, edit, and delete transactions and budget targets.

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** PostgreSQL (`psycopg2`)
- **Frontend:** HTML5, CSS3, Jinja2, Chart.js
